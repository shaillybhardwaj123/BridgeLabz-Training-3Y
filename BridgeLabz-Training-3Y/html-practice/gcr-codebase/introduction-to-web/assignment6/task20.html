The Role of the Head Section

The <head> element is a container for metadata (data about data) and is placed between the <html> tag and the <body> tag.

Metadata is not displayed on the webpage itself. It is read by the web browser to parse rendering instructions, by search engines for SEO indexing, and by external scripts/styles to customize behaviors.
