URI Encoding Demonstration

This page explains and demonstrates URI (Uniform Resource Identifier) character encoding in hyperlinks.

Encoding Special Characters in URLs

URIs only support a subset of ASCII characters. Special characters like spaces, ampersands, or slashes have syntactical meanings or are not allowed. To pass them safely in query strings, they must be percent-encoded:

  • Space character ( ) is encoded as %20
  • Ampersand character (&) is encoded as %26
